Privacy Policy

The Mechanism - Video Publisher. Last updated: 23 November 2026.

p>

Scope

This application is a personal tool used by its owner alone. It has no other users, no accounts and no sign-up.

What data is accessed

With the owner authorisation, the application accesses the owner own YouTube channels through the YouTube Data API in order to upload videos, set their titles, descriptions and thumbnails, and read the list of videos already published on those channels.

What data is stored

An OAuth refresh token is stored in a private repository controlled by the owner, so the application can publish without repeating the sign-in. No viewer data, analytics or personal information belonging to any other person is collected or processed.

What data is shared

Nothing is shared with third parties. No data is sold, transferred or used for advertising. Data is sent only to Google own APIs in order to perform the uploads described above.

Retention and deletion

The stored token can be revoked at any time by the owner at myaccount.google.com/permissions, which immediately ends all access. Deleting the token file removes the only stored credential.

Contact

Questions about this policy can be sent through the GitHub profile hosting this page.
